## 🚀 Featured Projects



### 🎙️ Audio Summarization Tool *(In Progress)*

> **Flask · OpenAI Whisper · LLMs · REST API**



An intelligent web application that transcribes audio files using **Whisper** and generates concise summaries powered by large language models. Designed for students, journalists, and professionals who need fast insight from recordings.



- 🔹 Speech-to-text transcription with Whisper ASR

- 🔹 LLM-powered abstractive summarization

- 🔹 Flask REST backend with clean API design

- 🔹 Handles multiple audio formats (mp3, wav, m4a)

### 🎬 MovieHub — Netflix Clone

> **React.js · TMDB API · CSS3 · JavaScript**



A fully responsive Netflix-inspired movie discovery platform built with React, consuming the TMDB API to display trending movies, TV shows, and detailed media pages.



- 🔹 Dynamic content fetched from TMDB REST API

- 🔹 Category-based browsing (Trending, Top Rated, Genre)

- 🔹 Responsive UI matching Netflix's design language

- 🔹 Component-based React architecture with hooks
